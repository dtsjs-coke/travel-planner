## 작업: 신규 페이지 "여행 도구함"(`/tools`) — 설계 + 백엔드 (senior-dev, orchestrator_pjt 위임)

사용자 요청: "여행 준비/여행 중에 쓸 수 있는 정말 유용한 여행 Tool을 웹으로. 가능하면 비용이 안 드는
기능으로, 정말 비용이 필요한 기능은 on/off로 설정할 수 있게."

오케스트레이터가 정한 구성(7개 도구): 환율 계산기 / 여행지 날씨 / 시차·세계시계 / 단위·사이즈 변환 /
여행 회화 카드(TTS) / 국가별 긴급정보 / **AI 번역(유일한 유료 기능)**.
이 세션은 **설계 + 백엔드**까지. 프론트는 ui-dev 후속(명세는 아래 "ui-dev 명세" 섹션).

### 1. 설계 결정 — [ADR-0014](../docs/adr/0014-travel-toolbox-free-apis-and-paid-feature-toggle.md)

- **도구 1~6은 백엔드 불필요로 확정.** 환율(`open.er-api.com`), 날씨(Open-Meteo geocoding + forecast)는
  키가 없고, 실제 응답 헤더를 curl로 확인한 결과 셋 다 `Access-Control-Allow-Origin: *`. 브라우저 → 제3자
  호출이라 우리 CORS/세션 쿠키 구조와 충돌하지 않는다. **단, 반드시 plain `fetch`로** 부를 것 — 기존
  `apiClient`(axios)는 `withCredentials: true`라 `ACAO: *`와 조합되면 브라우저가 CORS로 거부한다.
  CSP는 현재 없음(나중에 도입하면 세 도메인을 `connect-src`에 추가해야 함 → PROJECT.md Gotchas에 기록).
  Open-Meteo geocoding은 `language=ko` + 한글 도시명("오사카")으로도 검색되고 `timezone`/`country_code`를
  함께 준다(실확인) → 시계/통화/긴급정보 프리필에 재사용 가능.
- **유료 기능 토글 패턴**: `app_settings`에 기능별 bool 컬럼(ADR-0007), **기본 False**(무료 토글
  `route_sort_enabled`는 기본 True — 반대). 서버가 스스로 막는다: 인증 401 → 입력 422(500자·언어
  화이트리스트·source≠target) → 토글 403 → 일일 200회 서킷 브레이커 429 → 키 미설정 503. 외부 실패는
  재시도 없이 502. ADR에 "다음 유료 기능 추가 체크리스트"를 고정했다.

## ui-dev 명세 (여행 도구함 프론트)

### A. API 계약

**설정 (기존 엔드포인트 확장)**
- `GET /api/settings` 응답에 `ai_translate_enabled: boolean` 추가 (기본 `false`).
- `PATCH /api/settings` 바디에 `{"ai_translate_enabled": true|false}` 허용 (다른 필드와 함께 보내도 됨.
  null은 422 `"ai_translate_enabled must not be null"` — 안 바꾸려면 필드를 빼라).
- `types/models.ts`의 `AppSettings`에 `ai_translate_enabled: boolean`, `api/settings.ts`의
  `SettingsUpdateInput`에 `ai_translate_enabled?: boolean` 추가.

**번역 (신규)** `POST /api/ai/translate` (세션 필요, 기존 `apiClient` 사용)
```jsonc
// 요청
{ "text": "실례합니다, 역이 어디예요?", "source": "auto", "target": "ja" }
// source 생략 시 "auto". 언어 코드: ko en ja zh-CN zh-TW th vi id fr de es it pt ru
// 200 응답
{
  "translated_text": "すみません、駅はどこですか？",
  "pronunciation_ko": "스미마센, 에키와 도코데스카?",   // 목표가 ko면 null
  "romanization": "Sumimasen, eki wa doko desu ka?",   // 목표가 en/fr/de/es/it/pt/vi/id/ko면 null
  "source": "auto",
  "detected_source": "ko",                              // 코드 또는 "unknown"
  "target": "ja"
}
```
| 코드 | detail | 프론트 처리 |
|---|---|---|
| 401 | `Not authenticated` | 기존 처리 |
| 403 | `ai translate is disabled in app settings` | `['settings']` invalidate → 꺼짐 안내 화면으로 |
| 422 | `Value error, text must not be empty` / `text must be at most 500 characters` / `target must be one of: ...` / `source must be 'auto' or one of: ...` / `source and target must be different` | 폼 에러 표시 |
| 429 | `ai translate daily limit reached` | "오늘 한도 도달" 안내 |
| 502 | `AI translation failed` | "잠시 후 다시" + 다시 시도 버튼 |
| 503 | `GEMINI_API_KEY is not configured` | 관리자 설정 필요 안내 |

응답은 최대 30초 + Render 콜드스타트(30~50초)까지 걸릴 수 있다 → 로딩 상태 필수, 요청 중 버튼 비활성.

### B. `errorMessages.ts` 추가/수정 목록

### D. 진입점 / 프리필
- **여행 목록 헤더**(`TripListPage.tsx`, 톱니바퀴 옆)에 "도구함" 버튼 → `/tools`.
- **여행 상세**(`DayEditorPage.tsx` 헤더)에도 버튼 → `/tools?trip=<id>`. **프리필 권장(비용 0)**:
  1. 기존 쿼리 `['trips', id]`(`GET /api/trips/{id}`)로 `destination`, `start_date`, `end_date`, `currency` 획득.
  2. `destination`을 `[,/·]`로 잘라 첫 토큰으로 Open-Meteo geocoding(`language=ko&count=5`) → 첫 결과의
     `latitude/longitude/timezone/country_code`.
  3. 날씨 도시, 세계시계 두 번째 시간대, 긴급정보 국가, 회화 언어, 환율 대상 통화(`trip.currency`가 KRW가 아니면
     그 값, 아니면 `countries.ts`의 국가 통화)를 채운다. 사용자가 바꿀 수 있어야 함.
  4. geocode 실패/`destination` 없음 → 프리필 없이 수동 검색 UI 그대로. 에러로 취급하지 말 것.
  5. 날씨: 여행 시작일이 오늘부터 16일 이내면 예보 중 여행 기간 날짜를 강조, 그보다 멀면 "예보는 최대 16일 —
     지금은 현재 예보를 보여줍니다" 안내.
- `?trip` 없는 직접 진입이 기본 동작이다(프리필은 편의 기능).

### E. 외부 무료 API 호출 규칙 (중요)
- **`apiClient` 금지, plain `fetch` 사용**(credentials 없이). axios `withCredentials` 인스턴스로 부르면 CORS 실패.
- 호출 URL
  - 환율: `https://open.er-api.com/v6/latest/KRW` — **기준 통화 하나만 받아 교차환율 계산**
    (A→B = `rates[B] / rates[A]`) → 캐시 키 1개로 끝난다. `result !== "success"`면 실패 취급.
  - 지오코딩: `https://geocoding-api.open-meteo.com/v1/search?name=<q>&count=5&language=ko`
  - 예보: `https://api.open-meteo.com/v1/forecast?latitude=..&longitude=..&current=temperature_2m,weather_code&daily=weather_code,temperature_2m_max,temperature_2m_min,precipitation_probability_max&timezone=auto&forecast_days=16`
- 캐시(localStorage, 키에 버전 접두사)
  - `tools:fx:v1:KRW` — `{fetchedAt, time_last_update_unix, time_next_update_unix, rates}`.
    유효기간: `time_next_update_unix`까지(없으면 12시간). 이 API는 하루 1회 갱신이고 과호출 시 레이트리밋을 건다.
  - `tools:geo:v1:<소문자 trim 검색어>` — 30일.
  - `tools:wx:v1:<lat.toFixed(2)>,<lng.toFixed(2)>` — 1시간.
  - React Query를 쓰면 `staleTime`을 위 TTL과 맞추고 `retry: 1`.
- 실패 시 폴백 UX
  - 네트워크 실패 + 캐시 있음 → 캐시 값 표시 + "마지막 갱신: YYYY-MM-DD HH:mm (오프라인)" 배지. 에러 모달 금지.
  - 환율 캐시도 없음 → 수동 환율 입력칸으로 계산 가능하게.
  - 날씨 캐시도 없음 → "날씨 정보를 불러오지 못했습니다" + 다시 시도 버튼.
- 도시 검색은 제출 시 또는 디바운스 400ms + 2자 이상일 때만 호출(무료라도 레이트리밋 예의).
- **출처 표기 필수**: 환율 화면에 `<a href="https://www.exchangerate-api.com">Rates By Exchange Rate API</a>`,
  날씨 화면에 `Weather data by Open-Meteo.com`(링크). 두 서비스의 무료 이용 조건이다.
- 환율 값은 "참고용(실제 환전·카드 환율과 다름)" 문구 표시.

### F. 도구별 메모
- **세계시계**: `Intl.DateTimeFormat(..., { timeZone })`. 시간대 목록은 `Intl.supportedValuesOf('timeZone')`
  (미지원 브라우저면 `countries.ts`의 대표 시간대 목록으로 폴백). 서울 대비 시차(±h) 표시, 30초 간격 갱신,
  언마운트 시 interval 정리.
- **단위 변환**: °C↔°F, km↔mi, cm↔inch, kg↔lb, L↔US gal, 신발(한국 mm ↔ US/UK/EU, 남/여 구분), 옷(KR↔US/EU).
- **회화 카드**: 카테고리(인사/식당/교통/쇼핑/숙소/긴급) × 언어(최소 en, ja, zh-CN, th, vi + 가능하면 fr, es).
  카드 탭 → 크게 보기(현지인에게 화면 보여주기용). TTS: `speechSynthesis.cancel()` 후
  `new SpeechSynthesisUtterance(text)`에 `lang`(ja-JP, zh-CN, th-TH, vi-VN, en-US, fr-FR, es-ES…),
  `getVoices()`는 비동기 로드라 `voiceschanged` 이벤트 대기. 해당 언어 음성이 없으면 재생 버튼 비활성 +
  "이 기기에 해당 언어 음성이 없습니다". `speechSynthesis` 미지원이면 버튼 숨김.
- **긴급정보**: `countries.ts` 정적 데이터(경찰/구급/소방, 전압/주파수/플러그 타입, 팁 문화). 어느 국가든
  **외교부 영사콜센터 +82-2-3210-0404(24시간)**를 항상 상단에 `tel:` 링크로. "작성 시점 기준 정보 — 출발 전
