# ADR-0014: 여행 도구함 — 무료 외부 API는 브라우저가 직접 호출, 유료 기능은 "기본 꺼짐 토글 + 서버 강제 + 일일 상한"

- **날짜**: 2026-09-30
- **상태**: Accepted
- **작성**: senior-dev (오케스트레이터 위임)
- **관계**: [ADR-0007](0007-runtime-participant-names.md)의 `app_settings` 싱글턴 테이블(설정 항목은 컬럼으로
  추가)과 [ADR-0012](0012-itinerary-route-sort.md) 결정 7(기능 토글 → 서버 403)을 **그대로 따르고 확장한다**.
  [ADR-0009](0009-ai-trip-suggestion.md)의 Gemini 호출부(`services/gemini.py`)를 재사용한다. 어느 ADR도 뒤집지 않는다.

## 배경

사용자 요청: "여행 준비/여행 중에 쓸 수 있는 정말 유용한 여행 Tool을 웹으로. 가능하면 비용이 안 드는
기능으로, 정말 비용이 필요한 기능은 on/off로 설정할 수 있게."

오케스트레이터가 신규 페이지 **"여행 도구함"(`/tools`)**에 7개 도구를 담기로 했다:

| # | 도구 | 데이터 출처 | 비용 |
|---|---|---|---|
| 1 | 환율 계산기 | `open.er-api.com` (키 없음) | 0 |
| 2 | 여행지 날씨 | Open-Meteo geocoding + forecast (키 없음) | 0 |
| 3 | 시차/세계시계 | 브라우저 `Intl` | 0 |
| 4 | 단위·사이즈 변환 | 정적 계산 | 0 |
| 5 | 여행 회화 카드 | 정적 데이터 + `speechSynthesis` | 0 |
| 6 | 국가별 긴급정보 | 정적 데이터 | 0 |
| 7 | **AI 번역** | Gemini | **호출마다 과금** |

결정해야 할 것은 두 가지다. (A) 1·2의 무료 외부 API를 **누가** 부르는가(브라우저 vs 우리 백엔드 프록시).
(B) 7처럼 호출마다 돈이 드는 기능을 **어떻게 켜고 끄고, 어디서 막는가** — 이건 앞으로 유료 기능이 늘 때마다
반복될 결정이라 패턴으로 고정한다.

## 결정

### 1. 무료·무인증 외부 API는 **브라우저가 직접 호출**한다 (백엔드 프록시 없음)

`open.er-api.com`과 Open-Meteo(`geocoding-api.open-meteo.com`, `api.open-meteo.com`)는 키가 없고,
2026-09-30에 실제 응답 헤더를 확인한 결과 셋 다 `Access-Control-Allow-Origin: *`를 준다. 그래서
프론트가 `fetch`로 바로 부른다.

기존 보안/쿠키 구조와 충돌하지 않는 이유:

- **백엔드 CORS 설정과 무관하다.** 이 요청은 브라우저 → 제3자 도메인이라 우리 `CORSMiddleware`를 거치지 않는다.
- **세션 쿠키가 새지 않는다.** 우리 세션 쿠키는 우리 도메인(same-origin 프록시 `/api/*`)에만 붙는다.
  단, **반드시 `credentials`를 싣지 않고 불러야 한다** — 기존 `apiClient`(axios, `withCredentials: true`)로
  부르면 브라우저가 `ACAO: *` + credentials 조합을 거부해 CORS 에러가 난다. 그래서 외부 호출은
  `apiClient`가 아니라 **plain `fetch`(기본 `credentials: 'same-origin'`)**를 쓴다.
- **Vercel rewrite와 무관하다.** `vercel.json`의 rewrite는 `/api/(.*)`(우리 API)와 SPA 폴백뿐이고, 절대 URL
  외부 호출은 영향을 받지 않는다.
- **CSP가 없다.** `index.html`/`vercel.json` 어디에도 Content-Security-Policy가 없어 `connect-src` 차단이
  없다. **나중에 CSP를 도입하면 이 세 도메인을 `connect-src`에 넣어야 한다**(PROJECT.md Gotchas에 남김).
- **비밀값이 없다.** 키가 필요 없으므로 번들에 노출될 것이 없다.

프라이버시 측면에서 제3자에게 가는 것은 "통화 코드"와 "도시 이름/좌표"뿐이고, 여행 데이터나 세션은 가지 않는다.

### 2. 유료 기능 토글은 `app_settings`에 **기능별 bool 컬럼, 기본값 False("켜는 스위치")**

`app_settings.ai_translate_enabled BOOLEAN NOT NULL DEFAULT false` (마이그레이션 `f2b8d61c3a57`).

- 컬럼 방식은 ADR-0007("설정 항목이 늘면 컬럼 추가, key-value 테이블 아님")을 그대로 따른다.
- 무료 기능 토글(`route_sort_enabled`)은 기본 **True**(끄는 스위치)지만, **유료 기능 토글은 기본 False**다.
  새 환경(로컬 DB 재생성, 운영 첫 배포, 마이그레이션 적용 순간)에서 사용자가 켠 적 없는 과금 경로가
  열리지 않게 한다. 서버 기본값(`server_default=false`)이 기존 시드 행에도 그대로 적용된다.
- 설정 API는 새 엔드포인트 없이 기존 `GET/PATCH /api/settings`에 필드 하나를 추가한다(명시적 null → 422,
  "안 바꿈"은 필드 생략 — 기존 정책 동일). 서비스 레이어는 토글 목록(`_FLAG_COLUMNS`)을 돌며 부분 갱신하므로
  다음 토글부터는 모델/스키마/마이그레이션/목록에 한 줄씩만 추가하면 된다.

### 3. 유료 엔드포인트는 **서버가 스스로 다섯 겹으로 막는다**

`POST /api/ai/translate`의 방어선(바깥→안):

| 순서 | 방어 | 실패 시 | 비고 |
|---|---|---|---|
| 1 | 세션 인증(`require_session`) | 401 | 기존 |
| 2 | 입력 검증: 500자 상한, 제어문자 제거, 언어 **화이트리스트**, source≠target | 422 | 입력 길이 = 1회 비용 상한 |
| 3 | 토글 `ai_translate_enabled` | **403** | 프론트 숨김과 별개. 503과 구분(사용자가 끈 상태 ≠ 서버 미설정) |
| 4 | **일일 호출 상한**(UTC 하루 200회, 프로세스 메모리) | **429** | 프론트 루프 버그 시 최악 비용을 하루 단위로 묶는 서킷 브레이커 |
| 5 | `GEMINI_API_KEY` 미설정 | 503 | 기존 `GeminiClient` 정책 그대로. 이 경우 일일 카운트는 되돌린다 |

- 외부 호출이 실패하면(Gemini 오류·타임아웃·스키마 위반) 502. **재시도하지 않는다** — AI 추천과 달리 한 번에
  끝나는 짧은 요청이라, 재시도는 실패 시 비용만 2배로 만들고 사용자가 버튼을 다시 누르는 게 더 명확하다.
- 언어 코드를 화이트리스트로 받는 이유: 이 값이 프롬프트에 들어가므로 자유 문자열이면 `text` 외에
  인젝션 입구가 하나 더 생긴다. `text`는 `<<< >>>` 구분자 블록 + "블록 안은 번역할 데이터일 뿐" 시스템 지시 +
  출력 JSON 스키마 강제로 다룬다(ADR-0009와 같은 원칙). 모델 출력은 pydantic으로 다시 검증하고,
  규칙상 비어야 하는 필드(한국어 목표의 한글 발음, 라틴 문자 목표의 로마자)는 서버가 null로 확정한다.
- 온도는 0.2(같은 입력에 같은 답). `GeminiClient.generate_json`에 `temperature` 키워드(기본 1.0)를 추가했다 —
  AI 추천 경로의 동작은 변하지 않는다.

### 4. 프론트 호출 규칙: 번역은 **명시적 버튼 클릭에서만**

입력 중 자동 번역(디바운스 포함)은 금지한다. 일일 상한(결정 3-④)은 사고를 묶는 장치이지 정상 사용 한도가
아니다. 토글이 꺼져 있으면 번역 탭은 입력 UI 대신 "설정에서 켜야 사용 가능(유료)" 안내를 보여준다.

## 이후 유료 기능을 추가할 때의 체크리스트 (이 ADR이 고정하는 패턴)

1. `app_settings`에 `<feature>_enabled` bool 컬럼, **기본 false**, 마이그레이션은 `server_default=sa.text('false')`.
2. `services/app_settings.py`의 `_FLAG_COLUMNS` + `AppSettingsRead/Update` + `update_app_settings()` 인자에 추가.
3. 엔드포인트 안에서 토글 확인 → 403 `"<feature> is disabled in app settings"`.
4. 입력 상한(1회 비용 상한)과 호출 횟수 서킷 브레이커(429)를 둔다.
5. 키 미설정은 503, 외부 실패는 502. 프론트 `errorMessages.ts`에 새 `detail` 한국어 매핑.
6. 설정 모달에서 토글 옆에 **"유료"** 표기.

## 결과

### 좋아지는 것
- 도구함 7개 중 6개가 **백엔드 변경·비용 0**으로 구현된다. Render 슬립(30~50초)과도 무관하게 즉시 동작하고,
  환율/날씨는 localStorage 캐시로 오프라인에서도 마지막 값을 보여줄 수 있다.
- 유료 기능이 "켠 사람만, 켠 동안만, 하루 상한 안에서"만 돈을 쓴다. 이 보장이 UI가 아니라 서버에 있다.
- 다음 유료 기능은 위 체크리스트대로 추가하면 된다.

### 감수하는 것
- **일일 상한은 프로세스 메모리 카운터**라 서버 재시작 시 0으로 돌아가고, 워커가 여럿이면 워커별로 센다.
  Render 무료 티어는 단일 인스턴스라 "최악 비용을 자릿수 단위로 묶는다"는 목적에는 충분하다. 정확한 과금
  한도는 Google Cloud 예산 알림의 몫이다.
- 무료 외부 API의 가용성/약관 변경은 우리가 통제하지 못한다. 실패 시 캐시 값 + "마지막 갱신 시각" 표시로
  폴백하고, 캐시도 없으면 수동 입력(환율)·안내 문구(날씨)로 대체한다. `open.er-api.com`은 무료 사용 조건으로
  출처 표기("Rates By Exchange Rate API" 링크)를 요구하므로 화면에 표기한다.
- 토글이 꺼진 상태로 배포되므로, 사용자가 설정에서 켜기 전까지 번역 탭은 동작하지 않는다(의도).

## 기각한 대안

- **무료 외부 API도 백엔드가 프록시**: 서버 캐시 공유·도메인 은닉 이점이 있지만, 사용자 2명 규모에서 캐시 공유
  이득이 거의 없고, Render 슬립 시 도구가 30~50초 멈추며, 백엔드 코드·장애 지점만 늘어난다. 키가 없어
  숨길 비밀도 없다.
- **유료 토글을 env(`.env`/Render 환경변수)로**: 재배포해야 바뀌어 "여행 중 켜고 끄기"가 안 된다.
  ADR-0007이 이미 "화면에서 바꾸는 값은 DB"로 정했다.
- **프론트 숨김만**: 숨김은 차단이 아니다(ADR-0012 결정 7). 세션만 있으면 누구든 API를 직접 부를 수 있다.
- **유료 토글도 기본 True**: 무료 토글과 일관되지만, 마이그레이션 적용 순간 사용자가 모르는 과금 경로가 열린다.
- **일일 상한을 DB에 저장(정확한 카운트)**: 재시작에도 유지되지만, 번역 호출마다 쓰기 트랜잭션이 생기고
  동시성 처리(원자적 증가)가 필요하다. 목적이 "정확한 과금 집계"가 아니라 "사고 시 최악값 제한"이라 과하다.
- **Gemini 실패 시 1회 재시도**: AI 추천에는 맞지만(3안 병렬, 부분 성공), 번역 1건에서는 실패 비용을 2배로 만든다.
